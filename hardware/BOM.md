# Bill of materials

The bill covers one AmazingHand fitted with four magnetic fingertips (Index, Middle, Ring, Thumb).

| Component | Cost (USD) |
|---|---|
| AmazingHand kit | $99.48 |
| Magnetometer PCBs (4) | $100.51 |
| Teensy 4.0 | $23.02 |
| Servo adapter, multiplexer and shield | $19.09 |
| N52 magnets (20) | $9.68 |
| TPU and PLA filament | $2.49 |
| Wiring | $2.02 |
| **Total** | **$256.29** |

Prices were sourced in GBP (August 2026) and converted to USD. Filament quantities include support material.
