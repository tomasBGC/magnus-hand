# paper

The final figures. `fig_force_pred_vs_true`, `fig_level_confusion` and `fig_level_means` correspond to
`analysis/fig1_pred_vs_true.py`, `fig2_level_confusion.py` and `fig3_level_means.py`; the other two are
pictures of the hardware.

| File | What it shows |
|---|---|
| `fig_hand.png` | Three views of the AmazingHand fitted with the printed fingertips. |
| `fig_fingertip.png` | How a fingertip works (magnets move when the lattice is pressed, five sensors read the change) and its parts (TPU 95A lattice, PLA mount, five magnets). |
| `fig_force_pred_vs_true.pdf`, `.png` | Predicted versus true force, standard split and leave-one-scenario-out. |
| `fig_level_confusion.pdf` | Light/medium/firm confusion matrices. |
| `fig_level_means.pdf` | Load-cell force per finger at each cued grip level. |
