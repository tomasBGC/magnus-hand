## Deadband widening effectiveness (Index's own crosstalk sources)

Does widening `CROSSTALK_POSITION_DEADBAND_PCT` beyond the current 5% reduce Index's remaining false-contact sensitivity? Unlike the swing-based tables above (which measure raw polynomial sensitivity), this models the DEADBAND ITSELF: for a commanded position, quantizes it to each candidate grain, then finds the worst-case gap between the resulting correction and the TRUE correction needed for any physically-plausible true position within the backlash range. A wider bucket means fewer boundary crossings, but each crossing swings further (adjacent bucket centers are farther apart) -- this is a genuine trade-off, not something that can be assumed to favour either direction without checking.
